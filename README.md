# CleanCalc

Учебный portfolio demo лендинга для клининга квартир в Москве. Проект показывает, как можно собрать интерактивный калькулятор стоимости и времени уборки на обычных файлах без фреймворка и backend.

Это не сайт реальной клининговой компании. В проекте нет настоящих отзывов, клиентов, договоров, отправки заявок или коммерческих обещаний.

## Что реализовано

- Адаптивный лендинг с первым экраном, навигацией и mobile burger menu.
- Интерактивный калькулятор площади, типа уборки и допуслуг.
- Результат с ориентиром цены и примерным временем.
- Demo-форма заявки с проверкой пустых полей.
- Секции «Что входит», «Как работаем», объяснение ориентировочной цены и FAQ.
- Доступные labels для полей, `aria-expanded` для меню и заметные focus-состояния.

## Что отработано в проекте

- Калькулятор как главный интерактив страницы.
- Нормализация площади: пустое, маленькое и слишком большое значение не ломают результат.
- Граничные значения: `0`, отрицательная площадь, небольшая квартира, обычная квартира и большая площадь.
- Frontend-валидация заявки без backend.
- Mobile-first вёрстка: сначала удобный сценарий на телефоне, затем desktop-сетка.
- Demo-ограничения: цены примерные, форма ничего не отправляет, проект не имитирует реальную компанию.

## Как работает калькулятор

Расчёт выполняется в `script.js` на стороне браузера:

- базовая ставка за м² зависит от типа уборки;
- для маленьких квартир применяется минимальная цена;
- допуслуги добавляют фиксированную цену и время;
- цена округляется вверх до 100 ₽;
- время округляется вверх до 0,5 часа;
- площадь для учебного demo ограничена диапазоном от 10 до 300 м².

Типы уборки:

- поддерживающая — дешевле и быстрее;
- генеральная — дороже и дольше;
- после ремонта — самая дорогая и длинная.

## Технологии

- HTML;
- CSS;
- JavaScript без фреймворков;
- без backend и сборщика.

## Как открыть локально

Откройте файл `index.html` в браузере.

Для проверки через локальный сервер можно из папки проекта выполнить:

```bash
python -m http.server 4173
```

После этого страница будет доступна по адресу:

```text
http://localhost:4173
```

## Что проверять

- Меню на мобильной ширине открывается, закрывается и ведёт к секциям.
- Изменение площади, типа уборки и допуслуг сразу обновляет цену и время.
- Пустая форма показывает ошибки.
- Заполненная форма показывает demo-статус.
- На ширине около 390px нет горизонтального скролла.
- На desktop около 1366px нет горизонтального скролла.

## Ограничения

- Форма ничего не отправляет и не сохраняет.
- Цены и время демонстрационные.
- Нет backend, базы данных, CRM и интеграций.
- Точная цена в реальном сервисе зависела бы от состояния квартиры, загрязнения, мебели, доступа и срочности.

## Чему учит проект

- Работе с формами и проверкой полей.
- Разделению расчёта и обработки DOM.
- Обновлению состояния интерфейса без фреймворка.
- Mobile-first вёрстке.
- Честной подаче portfolio demo без фейковых доказательств.
